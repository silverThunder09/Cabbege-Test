# Git 작업 규칙

## 브랜치

- 기본 브랜치는 `main`, 개발 기준 브랜치는 `dev`다.
- Codex 작업 브랜치는 `codex/{topic}` 형식을 기본으로 사용한다.
- 작업 전 브랜치와 작업 트리를 확인한다.
- 사용자 변경을 덮어쓰거나 되돌리지 않는다.

## 커밋

- 사용자 승인 없이 커밋하지 않는다.
- 커밋은 하나의 목적만 담는다.
- 문서 변경과 구현 변경이 같은 규칙 변경이면 같은 브랜치에서 함께 관리한다.

## PR

- 사용자 승인 없이 PR을 만들지 않는다.
- PR에는 변경 이유, 주요 변경점, 테스트 결과를 적는다.
- ERD나 API 변경이 있으면 관련 문서 링크를 포함한다.
