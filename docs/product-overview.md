# 제품 개요

## 서비스 정의

배추마켓은 회원이 중고 상품 판매 게시글을 등록하고 관심상품, 문의, 채팅을 거쳐 단일 상품을 거래하는 서비스다. 결제는 PortOne 테스트 API로 성공 여부와 금액을 검증한다.

## 사용자

| 역할 | 주요 기능 |
|---|---|
| 비회원 | 상품 목록·상세, 검색, 판매자 프로필 조회 |
| 회원 | 상품 등록, 관심, 팔로우, 문의, 채팅, 쿠폰, 구매, 후기 |
| 관리자 | 카테고리, 쿠폰 이벤트, 회원 상태 관리 |

## 핵심 범위

- 회원가입, 로그인, 프로필
- 상품 임시저장·게시·수정·상태 변경·검색
- 이미지 최대 10장
- 관심상품, 팔로우, 공개 문의
- 상품별 1:1 실시간 채팅
- 선착순 쿠폰
- 직거래·택배거래 선택
- PortOne 테스트 결제 검증
- 거래완료 후 판매자 후기

## 제외 범위

- 장바구니와 다중 상품 주문
- 회원 주소와 배송지 저장
- 배송사, 송장번호, 배송 추적
- 활동 지역과 위치 기반 검색
- 실제 판매자 정산과 수수료
- 운영 환경의 실결제

## 과제 기술 목표

- LIKE 검색과 페이징
- Redis ZSet 인기 검색어
- Caffeine 로컬 캐시
- 선착순 쿠폰 동시성 제어
- QueryDSL 동적 검색과 인덱스 최적화
- STOMP 채팅과 커서 페이징
- CI/CD 및 부하 테스트
