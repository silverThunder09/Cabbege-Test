# 제품 개요

## 서비스 정의

배추마켓은 회원이 상품을 등록하고 좋아요, 문의, 팔로우, 채팅, 리뷰를 통해 거래를 진행하는 중고 거래 서비스다. 일부 상품은 경매 상태를 가질 수 있다.

## 사용자

| 역할 | 주요 기능 |
|---|---|
| 비회원 | 상품 목록·상세, 카테고리, 회원 공개 프로필 조회 |
| 회원 | 상품 등록, 좋아요, 문의, 팔로우, 채팅, 리뷰, 경매 입찰 |
| 관리자 | 카테고리, 회원 상태, 신고 대응 기능 확장 가능 |

## 핵심 범위

- 회원가입, 로그인, 로그아웃
- 내 정보 조회·수정
- 회원 공개 프로필 조회
- 카테고리 목록 조회
- 상품 등록, 임시저장, 수정, 삭제, 상태 변경
- 상품 이미지 관리와 대표 이미지 설정
- 상품 좋아요와 내 관심목록
- 상품 문의와 판매자 답변
- 회원 팔로우와 팔로워·팔로잉 목록
- 채팅방, 채팅 참여자, 메시지
- 회원 간 리뷰
- 상품별 경매 입찰

## 제외 범위

- 결제, 쿠폰, 주문, 배송지 저장
- 장바구니와 다중 상품 주문
- 실정산과 수수료
- 운영 결제 연동

## 설계 메모

- 결제·쿠폰·거래 테이블은 현재 ERD에서 제외한다.
- 경매는 `auction_status`를 통해 Item과 1:1로 관리한다.
- 채팅은 REST API와 `/ws/chat` WebSocket을 함께 사용한다.
